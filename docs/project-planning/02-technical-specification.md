## 3. API Specifications

### 3.1 Core Classes

#### 3.1.1 QA Signature

```python
class QA(dspy.Signature):
    """Question-Answering signature with conversation history.
    
    This signature defines the interface for a conversational AI system
    that maintains context through conversation history.
    """
    question: str = dspy.InputField(
        desc="The user's question or message"
    )
    history: dspy.History = dspy.InputField(
        desc="Previous conversation turns for context"
    )
    answer: str = dspy.OutputField(
        desc="The AI's response to the question"
    )
```

**Attributes:**
- `question` (str): User's current question
- `history` (dspy.History): Conversation history object
- `answer` (str): Model's response

**Validation:**
- `question` must be non-empty string
- `history` must be dspy.History instance
- `answer` generated by model


```python
dspy.History(
    messages=[
```

- ✅ Support secure config files

- ✅ Clear keys from memory

### 7.2 Input Validation

```python
def validate_input(question: str) -> tuple[bool, str]:
    """Validate user input for security.
    
    Checks:
        - Length within limits
        - No injection attempts
        - Valid character encoding
        - No malicious patterns
    """
    if not question or not question.strip():
        return False, "Empty input"
    
    if len(question) > 4096:
        return False, "Input too long"
    
    # Check for potential injection
    suspicious_patterns = ["<script", "DROP TABLE", "eval("]
    for pattern in suspicious_patterns:
        if pattern.lower() in question.lower():
            return False, "Suspicious input detected"
    
    return True, "Valid"
```

### 7.3 Data Protection

- Don't log sensitive information
- Encrypt saved conversations (optional)
- Sanitize outputs before display
- Clear sensitive data on exit

**Handling:**
- Prompt user to retry
- Explain validation rules
- Provide examples

### 8.2 Error Recovery

```python
def safe_predict(manager, question, max_retries=3):
    """Predict with automatic retry on failure."""
    for attempt in range(max_retries):
        try:
            return manager.ask(question)
        except APIError as e:
            if attempt == max_retries - 1:
                raise
            wait_time = 2 ** attempt
            print(f"Retry in {wait_time}s...")
            time.sleep(wait_time)
```
