# Product Guide: Federated Brain System - Agent-Driven Home OS

## Initial Concept

The Federated Brain system is pivoting from a passive Terminal User Interface (TUI) knowledge browser to an active, agent-driven home operating system. This transformation leverages the existing 60% complete implementation (miners, TUI, operations) as the foundation for an ADK/CopilotKit-based agentic system that provides automation, planning, and intelligent assistance.

**Key Transformation:**
- **From:** TUI-centric knowledge aggregation and browsing
- **To:** Agent-first automation platform with web UI, where the agent proactively acts on calendar conflicts, task management, and home automation using Google Workspace APIs.
