# Legacy Components

This directory contains the original components of the Federated Brain system, developed prior to the pivot to an agent-driven architecture. These components are functional and tested, but are archived here to make way for the new ADK/CopilotKit-based implementation.

## How to Restore

These components can be reintegrated into the new architecture in Phase 3 and beyond as monitoring and administration tools. For example, the Textual TUI can be adapted to display agent logs and provide a real-time monitoring dashboard.

To run the TUI standalone for debugging or demonstration purposes, you will need to follow the original setup instructions, which can be found in the commit history prior to the agent pivot.
